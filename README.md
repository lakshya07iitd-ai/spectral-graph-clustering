# Spectral Graph Clustering

A from-scratch implementation of spectral graph methods using Python and NumPy.

## Current Work

* Graph representation using adjacency and degree matrices
* Graph Laplacian \(L = D-A\)
* Laplacian eigenvalues and eigenvectors
* Fiedler vector and algebraic connectivity
* Laplacian quadratic form
* Connected component detection
* Numerical verification of spectral properties
